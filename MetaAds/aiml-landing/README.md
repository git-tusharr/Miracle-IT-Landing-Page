# AI & Machine Learning landing page

Miracle IT Career Academy. Plain HTML, CSS and JavaScript, no build step. Open `index.html`, or host the folder on any static host.

## Before running ads (same two settings as the Full Stack page)
Top of `js/main.js`: set `leadEndpoint` (Google Apps Script / CRM webhook) and `metaPixelId`. Until `leadEndpoint` is set, leads are only stored in the visitor's browser. The Apps Script from the Full Stack README works unchanged; the `course` column will read "AI & Machine Learning Course".

- Duration "about 5 months" and module lengths 4 / 6 / 4 / 6 weeks
- "Six projects", the project names, and the tools list (PyTorch, XGBoost, FastAPI, Docker, Colab)
