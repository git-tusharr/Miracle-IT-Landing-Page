🚀 Quick Checklist Before Launching Ads

1

Meta Pixel ID

Open js/main.js in each course folder and set metaPixelId: 'YOUR_ID' (line 10). The page will auto-fire PageView, Lead, and Contact events.

2

Lead CRM Webhook

Paste your Google Sheets Web App URL or CRM endpoint into leadEndpoint in js/main.js. The form submits name, phone, status, UTMs & Meta cookies.

3

Ad Manager URL

In Meta Ads Manager, set the campaign objective to Leads. Paste the generated Destination URL into the "Website URL" box for each ad.

4

Clean URL Aliases

Short aliases are active on the server: /meta/aiml, /meta/data-analytics, /meta/data-science, and /meta/fullstack redirect automatically.
