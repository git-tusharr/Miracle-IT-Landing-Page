# Data Science landing page

Miracle IT Career Academy. Plain HTML, CSS and JavaScript, no build step. Open `index.html`, or host the folder on any static host.

## Before running ads (same two settings as the Full Stack page)
Top of `js/main.js`: set `leadEndpoint` (Google Apps Script / CRM webhook) and `metaPixelId`. Until `leadEndpoint` is set, leads are only stored in the visitor's browser. The Apps Script from the Full Stack README works unchanged; the `course` column will read "Data Science Course".
